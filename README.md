# MenuToggle Discord Bot

MenuToggle is a Discord bot designed to provide a simple and intuitive way to toggle the visibility of a menu within a Discord server. This bot is perfect for server administrators who want to control the visibility of specific menus or channels with ease. It uses the discord.py library to interact with the Discord API and provides a straightforward command to toggle the menu's visibility.

## Install

To install MenuToggle, follow these steps:

1. Clone the repository to your local machine:
   ```bash
   git clone https://github.com/yourusername/MenuToggle.git
   ```
2. Navigate to the project directory:
   ```bash
   cd MenuToggle
   ```
3. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Create a `.env` file in the project directory and add your Discord bot token:
   ```env
   DISCORD_TOKEN=your_token_here
   ```
